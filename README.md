## 📌 Sobre o projeto

O **MovieCity** é um projeto desenvolvido com React e Vite, com o objetivo de praticar a criação de interfaces por meio de componentes reutilizáveis e estilização com CSS.

A página apresenta uma seleção de filmes, menu de navegação e adaptação para diferentes tamanhos de tela, proporcionando uma experiência visual agradável.

## ✨ Funcionalidades

| Recurso | Descrição |
|---|---|
| 🎥 Cards de filmes | Exibição de pôsteres de filmes. |
| 🧭 Navegação | Menu com opções de Filmes, Categoria, Sobre e Contato. |
| 🔐 Login | Botão de acesso na interface. |
| 📱 Responsividade | Layout adaptável a computadores, tablets e celulares. |
| 🍔 Menu mobile | Menu hambúrguer para telas menores. |
| 🎨 Efeitos visuais | Animações ao interagir com os cards. |

## 🛠️ Tecnologias utilizadas

- ⚛️ **React 19** — Construção da interface por componentes.
- ⚡ **Vite 7** — Ambiente de desenvolvimento e build.
- 💛 **JavaScript** — Implementação da lógica da aplicação.
- 🎨 **CSS3** — Estilização, animações e responsividade.
- 🔎 **ESLint** — Análise estática e padronização do código.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd NOME_DA_PASTA
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

```bash
npm run dev
```

Após iniciar o servidor, acesse o endereço exibido no terminal, geralmente:

`http://localhost:5173`

## 📱 Design responsivo

O MovieCity utiliza **Flexbox, CSS Grid e Media Queries** para adaptar sua interface a diferentes resoluções.

- 💻 Computadores: layout com duas colunas e cards organizados em grade.
- 📲 Tablets: conteúdo reorganizado para melhorar a visualização.
- 📱 Celulares: colunas empilhadas, cards em duas colunas e menu hambúrguer.
